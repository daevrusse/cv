# Portafolio profesional - David Mendoza

Sitio estático listo para publicar con GitHub Pages.

## Publicar
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `styles.css`, `main.js` y la carpeta `assets` manteniendo la estructura.
3. En GitHub: **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y carpeta `/ (root)`.
6. Guarda y espera a que GitHub genere la URL pública.

## Personalizar
- Foto: `assets/david-mendoza.png`
- CV descargable: `assets/CV_David_Mendoza.pdf`
- Textos: `index.html`
- Estilos: `styles.css`

No requiere frameworks ni instalación de dependencias.
